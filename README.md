# VibePod (formerly Deka)

**VibePod** — устанавливаемый веб-плеер (PWA) для музыки из публичных папок Яндекс Диска. Интерфейс вдохновлён классическими портативными плеерами. Проект разработан **без собственного backend-сервера** и не требует пользовательских аккаунтов.

> Репозиторий пока называется `Deka` — это прежнее название приложения. В самом приложении используется название **VibePod**.

## Возможности

- Открытие музыкальных коллекций по публичным ссылкам Яндекс Диска через его публичное API.
- Прослушивание аудио, управление очередью, избранным и сохранёнными треками.
- **Офлайн-прослушивание** предварительно сохранённых треков с использованием IndexedDB.
- Резервное копирование и восстановление библиотеки и настроек в JSON — **без включения аудиофайлов** в резервную копию.
- Настройка темы и цветовых акцентов.
- Установка в виде **PWA** с иконкой и запуском в отдельном окне; Service Worker сохраняет оболочку приложения для офлайн-открытия.

## Архитектура без собственного сервера

Приложение работает на стороне браузера:

- **HTML / CSS / JavaScript** — интерфейс и логика плеера.
- **Yandex Disk Public API** — получение содержимого публичных папок и ссылок на аудио.
- **IndexedDB** — локальное хранение сохранённой музыки.
- **localStorage** — пользовательские настройки, избранное и другие небольшие данные.
- **Service Worker + Web App Manifest** — PWA-функции и кеширование оболочки.

Для загрузки новой музыки требуется интернет и доступность соответствующих публичных ссылок. Ранее сохранённые треки могут воспроизводиться офлайн, если данные остались в хранилище браузера.

**Без собственного сервера** означает отсутствие отдельного приложения-backend и собственной базы пользователей. Для размещения статических файлов нужен хостинг, а для получения исходной музыки используются внешние серверы Яндекс Диска.

## Запуск

Структура репозитория — статический сайт. Основная страница: `index.html`.

1. Откройте сайт на HTTPS-хостинге, например GitHub Pages.
2. При необходимости установите его как приложение через браузер.
3. Добавьте публичную папку Яндекс Диска или используйте доступные источники.

Для корректной работы PWA и Service Worker нужен поддерживающий их браузер и защищённое окружение (HTTPS или localhost).

## Ограничения

- Приложение не хранит пользовательские треки на собственном сервере.
- Содержимое внешних папок и доступность ссылок зависят от их владельцев и Яндекс Диска.
- Офлайн-файлы хранятся на конкретном устройстве: очистка данных браузера может их удалить.
- Резервная копия JSON хранит настройки и ссылки, **а не сами музыкальные файлы**.

Проект — пример клиентской разработки и проектирования с ограничением на собственную серверную инфраструктуру.
